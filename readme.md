# My PyQT learning journey
This directory contains simple projects I created while learning PyQT. Nothing fancy...

### Modules used
**1. PyQT6:** For GUI development

**2. Matplotlib:** To graphically represent data

**3. Pillow:** To work with images using Python

### Clone the repostory
```bash
git clone https://github.com/Farhad8797/pyqt-gui-learning.git
```

### Install the required Modules
```bash
pip install -r requirements.txt
```
